# Hukuki Zeka — kurulum dosyaları

Bu depoda yalnız Hukuki Zeka'nın kurulum dosyaları durur; program yeni sürümleri buradan kendiliğinden indirir.

İndirme, kurulum ve kullanım kılavuzu: https://hukukizekanew.web.app

| Sistem | Dosya |
|---|---|
| Windows 10 / 11 (64 bit) | `HukukiZeka-Kurulum-<sürüm>.exe` |
| Mac — Apple Silicon (M1–M4) | `HukukiZeka-<sürüm>-mac-arm64.dmg` |
| Mac — Intel | `HukukiZeka-<sürüm>-mac-x64.dmg` |

Son sürüm: [Releases](https://github.com/avreax/hukuki-zeka-surumler/releases/latest)
